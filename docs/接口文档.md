# 校园二手商品交易系统 · 接口文档

> 版本：v1.0（对应 `需求设计文档.md` v1.0）
> 后端服务：`http://localhost:8081`
> 前端代理：`http://localhost:5174` → `/api/*` 转发到 8081

---

## 1. 通用约定

### 1.1 统一响应格式

**所有**接口（除文件上传的静态资源访问外）返回：

```json
{
  "code": 200,
  "message": "success",
  "data": { }
}
```

| code | 含义 | 前端处理 |
|:----:|------|----------|
| 200 | 成功 | 正常取 `data` |
| 400 | 参数错误 / 业务校验失败 | 弹 `message` |
| 401 | 未登录 / token 失效 | 清 token，跳登录页 |
| 403 | 无权限 | 弹"无权限访问" |
| 404 | 资源不存在 | 弹提示 |
| 500 | 服务器错误 | 弹通用错误提示 |

### 1.2 鉴权

- 登录成功后返回 `token`，前端存 `localStorage`
- 需鉴权的接口在请求头带：

```
Authorization: Bearer <token>
```

- **公开接口**（无需 token）：`/api/auth/**`、`/api/categories`、`/api/products`(GET)、`/api/sellers/**`、`/api/upload/**`
- **需 user 角色**：其余 `/api/**`
- **需 admin 角色**：`/api/admin/**`

### 1.3 分页约定

**请求参数**：`page`（默认 1）、`size`（默认 20）

**响应结构**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [ ],
    "total": 73,
    "current": 1,
    "size": 20,
    "pages": 4
  }
}
```

### 1.4 枚举定义

**商品状态 `ProductStatus`**

| 值 | 名称 | 说明 |
|:--:|------|------|
| 0 | PENDING | 待审核 |
| 1 | ON_SALE | 在售 |
| 2 | SOLD | 已售出 |
| 3 | OFF_SHELF | 已下架 |
| 4 | REJECTED | 已拒绝 |

**订单状态 `OrderStatus`**

| 值 | 名称 | 说明 |
|:--:|------|------|
| 0 | PENDING_PAY | 待付款 |
| 1 | PAID | 已付款 |
| 3 | FINISHED | 已完成 |
| 4 | CANCELLED | 已取消 |

> 注：**不存在 2（已发货）**，本项目不做邮寄，编号保留与参考项目对照。

**成色 `ConditionLevel`**（字符串）

`全新` / `几乎全新` / `轻微使用痕迹` / `明显使用痕迹`

**行为类型 `BehaviorType`**

| 值 | 名称 |
|:--:|------|
| 1 | VIEW 浏览 |
| 2 | FAVORITE 收藏 |
| 3 | PURCHASE 购买 |

**支付方式 `PayMethod`**

| 值 | 名称 |
|:--:|------|
| `alipay` | 支付宝 |
| `wechat` | 微信支付 |

## 3. 认证模块

### 3.1 注册

```
POST /api/auth/register
鉴权：公开
```

**请求体**

| 字段 | 类型 | 必填 | 校验 | 说明 |
|------|------|:----:|------|------|
| username | string | ✅ | 4~20 字符，唯一 | 登录名 |
| password | string | ✅ | 6~20 字符 | 密码 |
| nickname | string | ❌ | ≤50 字符 | 昵称，留空取 username |
| phone | string | ❌ | `^1[3-9]\d{9}$` | 手机号 |

```json
{
  "username": "student04",
  "password": "123456",
  "nickname": "小明",
  "phone": "13800138000"
}
```

**响应**

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "id": 7,
    "username": "student04",
    "nickname": "小明",
    "phone": "13800138000",
    "avatar": null,
    "role": "user",
    "status": 1,
    "createTime": "2026-09-22T18:00:00"
  }
}
```

**错误**

| code | message | 场景 |
|:----:|---------|------|
| 400 | 用户名已存在 | 重名 |
| 400 | 用户名长度需在 4~20 字符之间 | 校验失败 |
| 400 | 手机号格式不正确 | 手机号非法 |

> ⚠️ **响应中绝不包含 password 字段**。

---

### 3.2 登录

```
POST /api/auth/login
鉴权：公开
```

**请求体**

| 字段 | 类型 | 必填 |
|------|------|:----:|
| username | string | ✅ |
| password | string | ✅ |

**响应**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "nickname": "管理员",
      "avatar": null,
      "role": "admin"
    }
  }
}
```

> 前端拿到后：`localStorage.setItem('token', data.token)`、`localStorage.setItem('user', JSON.stringify(data.user))`

**错误**

| code | message | 场景 |
|:----:|---------|------|
| 400 | 用户名或密码错误 | 用户不存在 **或** 密码错误（**合并提示，不泄漏账号是否存在**） |
| 403 | 账号已被禁用 | status=0 |

### 5.2 商品详情

```
GET /api/products/{id}
鉴权：公开
```

**响应**：在列表字段基础上增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| description | string | 完整描述 |
| updateTime | datetime | 更新时间 |
| isFavorited | boolean | **当前登录用户是否已收藏**（未登录恒为 false） |
| seller | object | 卖家信息（见下） |

```json
{
  "seller": {
    "id": 2,
    "nickname": "小明",
    "avatar": null,
    "onSaleCount": 5,
    "soldCount": 12
  }
}
```

**副作用（重要）**：

- 浏览量 `view_count` +1 —— **独立操作，不能因为别的接口调用而虚增**
- 若已登录且**不是自己**的商品，写入 `user_behavior`（type=1 浏览）

**错误**：`404 商品不存在`；若商品 status 为 0/3/4 且**访问者不是所有者、不是管理员** → `404`

### 5.3 发布商品

```
POST /api/products
鉴权：需登录
```

**请求体**

| 字段 | 类型 | 必填 | 校验 |
|------|------|:----:|------|
| title | string | ✅ | 5~100 字符 |
| description | string | ❌ | ≤1500 字符 |
| categoryId | int | ✅ | 必须是存在的二级分类 |
| conditionLevel | string | ✅ | 枚举四值之一 |
| price | decimal | ✅ | > 0，两位小数 |
| originalPrice | decimal | ❌ | 若填则 ≥ price |
| images | array | ❌ | 最多 9 个 URL |
| brand | string | ❌ | ≤50 字符 |
| tradePlace | string | ✅ | ≤100 字符 |

```json
{
  "title": "【九成新】索尼WH-1000XM5 头戴式降噪耳机",
  "description": "去年买的，用了一学期，功能完好无维修，配件齐全。宿舍自提或东区食堂交易。",
  "categoryId": 104,
  "conditionLevel": "轻微使用痕迹",
  "price": 1280.00,
  "originalPrice": 2899.00,
  "images": ["/uploads/20260922/abc123.jpg"],
  "brand": "Sony/索尼",
  "tradePlace": "东区食堂门口"
}
```

**响应**：`{"code":200,"message":"发布成功，等待管理员审核","data":{"id":74}}`

> 新商品 `status=0`（待审核），**不会立即出现在列表里**。

**错误**：`400 价格必须大于0`、`400 原价不能低于现价`、`400 图片最多9张`

---

### 5.4 编辑商品

```
PUT /api/products/{id}
鉴权：需登录，且必须是商品所有者
```

**请求体**：同发布，字段全部可选（只传要改的）。

**业务规则**：

- 只能编辑 **status=1（在售）或 3（已下架）** 的商品
- 编辑后**不重置审核状态**（已上架的商品改价不用重新审核）

**错误**：`403 无权操作此商品`、`400 已售出的商品不能编辑`

---

### 5.5 下架商品

```
PUT /api/products/{id}/off-shelf
鉴权：需登录，且是所有者
```

**效果**：`status: 1 → 3`

**响应**：`{"code":200,"message":"下架成功","data":null}`

> 参考项目把"下架"写成了 status=2（与"已售出"混用），本项目用 **3=已下架**。

---

### 5.6 删除商品

```
DELETE /api/products/{id}
鉴权：需登录，且是所有者
```

**业务规则**：

- 只能删除 **status≠2（未售出）** 的商品
- 若已有订单关联，**拒绝删除** → `400 该商品已有订单记录，不能删除`

---

### 5.7 我发布的商品

```
GET /api/products/mine
鉴权：需登录
```

**查询参数**：`page`、`size`、`status`（可选，按状态筛选）

**响应**：分页结构，`records` 为商品对象（含所有状态）。

## 7. 收藏模块

### 7.1 收藏商品

```
POST /api/favorites/{productId}
鉴权：需登录
```

**业务规则**：

- 不能收藏**自己的**商品 → `400 不能收藏自己的商品`
- 重复收藏**幂等成功**（不报错，也不重复 +1）
- 副作用：`product.favorite_count` +1；写入 `user_behavior`（type=2）

**响应**：`{"code":200,"message":"收藏成功","data":{"favoriteCount":19}}`

---

### 7.2 取消收藏

```
DELETE /api/favorites/{productId}
鉴权：需登录
```

**副作用**：`favorite_count` -1（**不低于 0**）；**不写入**行为表。

**响应**：`{"code":200,"message":"已取消收藏","data":{"favoriteCount":18}}`

---

### 8.1 创建订单

```
POST /api/orders
鉴权：需登录
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| productId | int | ✅ | 商品ID |
| buyerRemark | string | ❌ | 买家备注，≤255 字符 |

**业务校验**

| 校验 | 失败提示 |
|------|----------|
| 商品存在 | `400 商品不存在` |
| 商品 status=1 | `400 商品已售出或已下架` |
| 买家 ≠ 卖家 | `400 不能购买自己发布的商品` |

**效果**：创建订单（status=0 待付款），**此时商品状态不变**（付款时才锁定）。

**响应**

```json
{
  "code": 200,
  "message": "下单成功，请尽快完成支付",
  "data": {
    "id": 34,
    "orderNo": "ORDER1758532800000a1b2c3d4",
    "productId": 12,
    "productTitle": "【九成新】索尼WH-1000XM5 头戴式降噪耳机",
    "productImage": "https://picsum.photos/seed/a1/400",
    "price": 1280.00,
    "status": 0,
    "statusText": "待付款",
    "tradePlace": "东区食堂门口",
    "createTime": "2026-09-22T18:00:00"
  }
}
```

### 8.2 支付订单

```
PUT /api/orders/{id}/pay
鉴权：需登录（必须是买家本人）
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| payMethod | string | ✅ | `alipay` / `wechat` |

**业务校验**

| 校验 | 失败提示 |
|------|----------|
| 订单存在且属于当前买家 | `403 无权操作此订单` |
| 订单 status=0 | `400 订单状态不是待付款` |
| **乐观锁**：`UPDATE product SET status=2 WHERE id=? AND status=1` | 影响行数 0 → `400 该商品已被其他买家购买` |

**成功后的状态变更（同一事务）**

1. `product.status`: 1 → 2（已售出）
2. `order.status`: 0 → 1（已付款）
3. `order.pay_method` = 传入值
4. `order.pay_time` = now
5. 写入 `user_behavior`（type=3 购买）

**响应**：`{"code":200,"message":"支付成功","data":{...订单对象}}`

> ⚠️ **这是本项目最关键的并发点**。乐观锁通过 SQL 的 `WHERE status=1` 条件实现原子性，比"先查再改"可靠。

---

### 8.3 确认完成

```
PUT /api/orders/{id}/complete
鉴权：需登录（必须是买家本人）
```

**业务校验**：订单 status 必须 = 1（已付款）

**效果**：`order.status`: 1 → 3；`order.finish_time` = now

**响应**：`{"code":200,"message":"交易完成","data":{...}}`

---

### 8.4 取消订单

```
PUT /api/orders/{id}/cancel
鉴权：需登录（必须是买家本人）
```

**业务校验**：订单 status 必须 = 0（待付款）

**效果（同一事务）**：

1. `order.status`: 0 → 4（已取消）
2. 若 `product.status = 2`，恢复为 1（重新上架）

> 本项目"下单不锁商品"，所以取消时**通常不需要恢复商品状态**；此逻辑为兼容"已付款后由管理员取消"等扩展场景保留。

## 9. 文件上传模块

### 9.1 上传图片

```
POST /api/upload/image
鉴权：需登录
Content-Type: multipart/form-data
```

**请求**：表单字段名 `file`

**限制**

| 项 | 限制 |
|----|------|
| 文件类型 | `image/jpeg`、`image/png`、`image/gif`、`image/webp` |
| 文件大小 | ≤ 5MB |

**响应**

```json
{
  "code": 200,
  "message": "上传成功",
  "data": { "url": "/uploads/20260922/abc123.jpg" }
}
```

> 前端把返回的 `url` 收集进 `images` 数组，发布商品时一起提交。
> 静态资源访问：`GET /uploads/**`（**公开**，不走鉴权）

**错误**：`400 只能上传图片文件`、`400 图片大小不能超过5MB`

## 11. 错误码汇总

| code | 场景举例 |
|:----:|----------|
| 400 | 参数校验失败、业务规则不满足（如"不能买自己的商品"、"价格必须大于0"） |
| 401 | 未带 token、token 过期或非法 |
| 403 | 非管理员访问 `/api/admin/**`、操作他人资源 |
| 404 | 商品/订单/用户不存在 |
| 500 | 未预期的服务器异常（**不返回堆栈**） |

**统一异常处理**：`@RestControllerAdvice` 捕获：

- `MethodArgumentNotValidException`（参数校验）→ 400 + 第一条校验失败信息
- `BusinessException`（自定义业务异常）→ 400 + 自定义 message
- `Exception`（兜底）→ 500 + "服务器内部错误"
