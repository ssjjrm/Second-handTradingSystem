## 二、全局框架（所有页面共有）

### 2.1 顶部导航栏（黄色背景）

从左到右：

| 位置 | 元素 | 说明 |
|------|------|------|
| 左 | Logo「闲鱼」 | 黑色设计体字 |

### 2.3 右侧悬浮工具栏（垂直固定）

### 2.4 右下角悬浮窗

「满意度调研 / 期待您的意见」卡通形象浮窗 —— **我们不做**。

## 三、首页布局

从上到下：

1. **顶部导航**（见 2.1）
2. **公告横幅**（见 2.2）
3. **核心推荐区**（三栏）：
   - **左栏**：白色圆角卡片，**10 行分类入口**：
     `手机/数码/电脑`、`服饰/箱包/运动`、`技能/卡券/潮玩`、`母婴/美妆/个护`、`家具/家电/家装`、`文玩/珠宝/礼品`、`食品/宠物/花卉`、`图书/游戏/音像`、`汽车/电动车/租房`、`五金/设备/农牧`
   - **中栏**：橙色大促销位（文案 + "去看看 >"按钮）
   - **右栏**：**2×2 推荐网格**，四个彩色块（黄/蓝/绿/粉），每块左侧标题 + 右侧两张商品图 + 价格
4. **频道 Tab 栏**：一排圆形胶囊按钮，首个「猜你喜欢」为选中态
   后续：`个人闲置`、`BJD娃娃`、`垂钓`、`吉他乐器`、`台球`、`摄影摄像`、`钱币收藏`、`女装穿搭`、`居家好物`、`大牌美妆`、`机车`
5. **商品瀑布流**：**每行 5 列**

> ⚠️ **用户决策**：第 3 项的"推荐区"（中栏促销位 + 右栏 2×2 网格）**不做**，首页直接从分类 + 商品列表开始。

## 四、搜索结果页布局

从上到下：

1. 顶部导航（搜索框内是当前关键词，如「头戴式耳机」）
2. 公告横幅
3. **筛选排序区**（两行）：
   - **第一行**：排序下拉 `综合` / `新降价` / `新发布` / `价格` ＋ **价格区间**两个输入框 `¥ [ ] - ¥ [ ]` ＋ **区域**下拉 ＋ **分页器** `< 1/50 >`
   - **第二行**：属性标签复选：`个人闲置`、`验货宝`、`验号担保`、`包邮`、`超赞鱼小铺`、`全新`、`严选`、`转卖`
4. **商品网格**：每行 5 列
5. 右侧悬浮工具栏、右下角浮窗

## 五、商品详情页布局

从上到下：

1. **卖家信息栏**：
   - 左：卖家头像、昵称（`小虾米爱游泳`）、认证标签（`小铺L3`、`卖家信用极好`）
   - 中：地理位置 + 活跃数据（`汕头`、`刚刚来过`、`来闲鱼1年`、`卖出752件宝贝`、`好评率82%`）
   - 右：`闲鱼号` 按钮
2. **主体区（左右分栏）**：
   - **左栏（约 45%）**：最左一列**垂直缩略图**（5~6 张），紧邻右侧一张**大主图**
   - **右栏（约 55%）**：
     - 顶部：右上角「**全新**」标签
     - 价格区：`活动价 ¥46.00` ＋ `包邮`；下方 `246人想要 | 6365浏览`
     - 标题与描述：标题 + 长描述 + 「展开」按钮
     - **参数网格（双列）**：`品牌: Sony/索尼`、`型号: WH-1000XM5`、`成色: 全新`、`款式: 头戴式`、`功能状态: 功能完好无维修`
     - **底部操作按钮**：`聊一聊`（黄）、`立即购买`（黑）、`收藏`（白+星星图标）
3. 右侧悬浮工具栏、右下角浮窗

## 六、发布闲置页布局

**极其简洁**，从上到下：

```
发闲置
├── 基础信息
│   ├── 宝贝图片 *        → 「+ 添加首图」上传框
│   ├── 宝贝描述 *        → 输入框，placeholder「描述一下宝贝的品牌型号、货品来源...」，计数 0/1500
│   └── 属性规格          → 提示「上传主图/填写内容后将为你智能识别属性」
├── 价格
│   ├── 价格 *
│   └── 原价
└── [发布] 按钮
```

> 🔑 **关键发现**：闲鱼**没有独立的"分类选择器"和"成色选择器"**。
> 分类与成色都是靠"**智能识别属性**"从图片/描述自动提取的。
> 我们的项目不做 AI 识别（D 阶段再说），所以**必须补上显式的分类下拉 + 成色单选**。

  ```
  我的闲鱼
  ```

## 九、我们的取舍（对应需求文档）

| 闲鱼功能 | 我们做不做 | 理由 |
|----------|-----------|------|
| 顶部黄色导航 + 搜索 | ✅ 做 | 核心骨架 |
| 热搜词 | ✅ 做（静态词） | 成本极低，观感提升 |
| 公告横幅 | ✅ 做 | 一行文案 |
| 左侧分类菜单 | ✅ 做（按我们的分类体系） | 核心导航 |
| 首页推荐区（促销位+2×2网格） | ❌ **不做**（用户已定） | 直接进商品列表 |
| 商品瀑布流 5 列 | ✅ 做 | 核心展示 |
| 频道 Tab | ⚠️ 简化为"分类 Tab" | 用我们的分类替代 |
| 排序 + 价格区间 + 分页 | ✅ 做 | 核心筛选 |
| 区域筛选 | ❌ 不做 | 校园场景 → 改为「**交易地点**」筛选 |
| 属性复选标签（验货宝等） | ❌ 不做 | 平台特色功能，不适用 |
| **聊一聊** | ❌ 不做（暂缓） | 聊天功能砍掉 |
| **收藏（想要）** | ✅ 做 | 用户已选 |
| 卖家信息栏 | ✅ 做，但**去掉好评率** | 我们不做评价体系 |
| 参数网格 | ✅ 做 | 展示分类/成色/品牌/交易地点 |
| 「智能识别属性」 | ❌ 不做 | 后期 D 阶段可考虑 |
| 右侧悬浮工具栏 | ⚠️ 简化 | 只保留「发闲置」 |
| 满意度调研浮窗 | ❌ 不做 | 无关 |
| 信用/评价体系 | ❌ 不做 | 用户已排除 |
| 粉丝/关注 | ❌ 不做 | 用户已排除 |
