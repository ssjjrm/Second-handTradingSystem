# S10 前端布局与视觉设计方案（仿闲鱼）

> **依据**：`闲鱼页面截图/` 下 5 张实拍截图 + `docs/设计参考-闲鱼逆向分析.md` + `需求设计文档.md` §7§8。
> **约束**：接口已全部冻结（35 个业务接口 + 1 个调试开关），本阶段**只改前端**，不改任何接口。
> **交付**：把 S3~S9 的"能跑"页面，改成"看起来像个二手交易平台"的页面。

---

## 0. 一页纸结论

| 项 | 决定 |
|---|---|
| 视觉目标 | 黄顶栏 + 白卡片 + 橙红价格 + 5 列商品流，**神似即可，不逐像素还原** |
| 容器 | 1200px 居中，页面底色 `#F7F8FA` |
| 新增页面 | `/products`（列表）、`/product/:id`（详情）、`/publish`（发布） |
| 改造页面 | 首页、个人中心（Tab → 左侧菜单）、卖家主页、登录、注册 |
| 不动页面 | 管理后台**只换配色不改布局**（已验收的东西不折腾） |
| 组件库 | ❌ **不引入 Element Plus**（理由见 §9.2） |
| 新增组件 | 13 个（见 §8），全部手写 scoped CSS |
| 动效 | 只做 6 处，全部 ≤ 350ms，且尊重 `prefers-reduced-motion` |
| 删除 | `frontend/public/verify/` 整个目录（S10 最后一步） |

### 3.1 顶栏 `AppHeader.vue`（所有 C 端页面共用）

```
┌────────────────────────────────────────────────────────────────────┐ 黄底 #FFD100
│ 校园二手        ┌───────────────────────────────┐   [发布闲置]  (头)昵称▾ │ 高 58

└────────────────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 高度 | 主行 58px + 热搜行 26px = **84px**，`position: sticky; top: 0` |
| Logo | "校园二手" 28px / 800 / `#1A1A1A`，点击回 `/` |
| 搜索框 | 宽 460px、高 36px、白底、`--radius-pill`、内嵌右侧圆角搜索按钮（56px 宽，深色字） |
| 热搜词 | **静态 8 个词**（与种子数据的品牌/分类对齐：耳机、自行车、教材、显示器、吉他、台灯、篮球、行李箱），点击 = 跳 `/products?keyword=x` |
| 右侧（已登录） | `[发布闲置]`（黑底白字胶囊）+ 圆形头像 32px + 昵称 + `▾` 下拉（个人中心 / 我的收藏 / 管理后台* / 退出登录） |
| 右侧（未登录） | `[登录]`（描边）`[注册]`（黑底白字） |
| 下拉实现 | 纯 CSS `:hover` + `focus-within`（不做点击外部关闭的 JS，够用） |
| 管理员才显示「管理后台」 | 读 `user.role === 'admin'` |

> 💡 搜索框的 `keyword` 用 `router.push({ path:'/products', query:{ keyword } })`，
> 不在顶栏里直接发请求 —— 顶栏只管导航，数据归列表页管。

### 3.2 公告条 `NoticeBar.vue`

白底、高 40px、圆角 8、左侧 📢、右侧 `×`；关闭状态存 `localStorage`（`notice-closed`）。
文案：「校园内当面交易，平台不涉及收款 —— 请确认实物后再付款。」

### 3.3 右侧悬浮工具栏 `FloatingBar.vue`

截图有 6 个（发闲置/消息/商品码/APP/反馈/客服）。**我们只留 3 个**：

|------|------|

| 我的 | `/profile` 或 `/login` |

样式：`position: fixed; right: 24px; top: 40%;` 白底圆角 12、`--shadow-hover`，每项 48×48、图标 + 10px 文字。

### 3.4 页脚 `AppFooter.vue`

一行灰字：`校园二手交易平台 · 课程项目 · 仅供学习演示`。高度 60px，居中。

| 侧栏交互 | hover 背景 `#FAFAFA` + 文字 `#FF5000`；点击 → `/products?categoryId={id}` |
| 分类 Tab | 胶囊横排，「猜你喜欢」选中态（黄底黑字），其余白底；点击切换 `categoryId` 过滤，**不跳页**（就地刷新商品流） |
| 商品流 | `grid` + `repeat(4, 1fr)` + `gap: 12px`；首屏 20 条，底部「加载更多」按钮（加分页器会让首页显得重） |

> 4 列 = 231px/张，和列表页 5 列的 230px/张**视觉密度一致**。
> 用同一个卡片组件 + `auto-fill` 就能自适应，不需要两套样式。

## 5. P02 商品列表 `/products`

```
┌ AppHeader（搜索框里是当前 keyword）────────────────────────────┐
├ NoticeBar ────────────────────────────────────────────────────┤
┌ 筛选卡（白，圆角，padding 12 16）────────────────────────────────┐
│ [综合▾] [最新发布] [价格 ↑↓]  │ 成色[▾] 交易地点[____]         │
│ 价格区间 [¥___]-[¥___] [确定] │ 分类：数码电子 / 手机（可 × 清除）│
└───────────────────────────────────────────────────────────────┘
  共 53 件                      ← 结果计数（左）
┌───────────────────────────────────────────────────────────────┐
│ 5 列商品网格（gap 12）                                          │
└───────────────────────────────────────────────────────────────┘
                    [ < ] 1 2 3 … 8 [ > ]    每页 20
```

| 区块 | 规格 / 行为 |
|------|------------|
| 排序 | 四个选项映射接口 `sort`：综合=默认、最新发布=`newest`、价格升=`priceAsc`、价格降=`priceDesc`（点击价格在升降间切换，显示 ↑/↓） |
| 成色筛选 | 下拉：全新 / 几乎全新 / 轻微使用痕迹 / 明显使用痕迹 → `conditionLevel` |
| 交易地点 | 输入框 → `tradePlace`（模糊匹配） |
| 价格区间 | 两个数字输入 → `minPrice` / `maxPrice`；**校验 min ≤ max**，不合法给红字提示且不发请求 |
| 分类面包屑 | 从 `?categoryId=` 反查分类名，显示「数码电子 / 手机 ×」，点 × 清除 |
| 分页 | 自制 `AppPagination`：上一页 / 页码（最多 7 个，中间省略号）/ 下一页；每页 20 |
| 空结果 | `EmptyState`：「没找到相关商品」+ 副文案「换个关键词，或者看看首页」+ [回首页] 按钮 |
| 加载中 | 10 个骨架卡（`ProductSkeleton`），不显示"加载中…"文字 |
| URL 同步 | 所有筛选条件同步到 query string（刷新/分享/后退都能还原） |

| 图片上传 | `<input type="file" accept="image/*" multiple>` + `FormData` → `POST /api/upload/image`；上传中显示进度遮罩；**限制 9 张**、单张 ≤5MB（前端先挡，后端也挡） |
| 二级分类联动 | 选一级 → 拉 `/api/categories` 里该节点的 `children`；**没选二级时禁止提交**（后端也会 400） |
| 成色 | 四个胶囊单选（不是 select，点起来快），值直接传后端枚举文案 |
| 校验 | 全部前端先校验一遍（标题 5~100、价格 >0、分类必选、交易地点必填、联系方式已填）；后端仍会再校验 —— 前端校验只为体验 |
| 未填联系方式 | 顶部黄条拦截：「发布前请先填写微信号或 QQ」+ [去设置] → `/profile`，**不让他白填一表单** |
| 提交成功 | toast「已提交，等待管理员审核」→ 跳 `/profile?tab=published`；若审核开关关闭（响应里 status 不确定）→ 文案改成「发布成功，已上架」 |
| 编辑模式 | 同一组件可复用于 `/publish?id=xx`（预填现有数据，调 `PUT /api/products/{id}`）——**S10 只做发布，编辑留到 S11 视时间决定** |

> 💡 主页截图里闲鱼是「图片 + 描述 + 价格」三项极简。
> 我们多出来的分类/成色/品牌/交易地点是**功能刚需**（数据库 NOT NULL 或筛选依赖），
> 所以用两栏布局把它们塞进「基础信息」，不额外增加页面高度。

| 考虑 | 结论 |
|------|------|
