S3 用户模块 · 接口验证

打开方式：http://localhost:5174/verify/s3-auth.html（必须先启动前端 dev server）
为什么不能双击打开：file:// 和 localhost:5174 的 localStorage 是隔离的， 双击打开就读不到登录页存的 token。

登录态：检查中…

1. 登录　POST /api/auth/login 用户名 密码 期望：HTTP 200，返回 token，并自动存进 localStorage
2. 当前用户信息　GET /api/auth/me 期望：200，含 phone / hasContact / stats
3. 修改资料　PUT /api/auth/profile 昵称
4. 修改密码　PUT /api/auth/password 原密码 新密码 期望：原密码错 → 400「原密码错误」
5. 未登录 / 坏 token
